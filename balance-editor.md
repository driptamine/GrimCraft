# Balance Editor

Откройте `/balance` или кнопку **Balance Editor** в главном меню. Редактор загружается отдельно от симуляции, без Three.js, моделей, карты и игрового цикла.

Первая версия редактирует профили стрелкового оружия. Юниты, экономика, здания, ближний бой и гранатомёты пока не входят в редактор.

## Создание мода

1. Задайте название, ID и версию.
2. Выберите расу и оружие.
3. Выберите модель урона:
   - **Готовый DPS** сохраняет существующую таблицу. Min/Max/AP в этом режиме не меняют урон. Изменение интервала сохраняет заданный DPS.
   - **Base Damage × Armour Piercing** использует Min/Max, Min.D, AP, точность и Refire. DPS вычисляется автоматически. Увеличение Refire уменьшает DPS без увеличения урона попадания.
4. В режиме AP заполните все 15 классов брони. Пустое значение означает неизвестный AP, а не ноль. Кнопка оценки AP не заполняет значения, скрытые нижним пределом урона. Оценки по округлённому DPS приблизительны.
5. Используйте Undo/Redo, сброс поля или сброс оружия. Черновик с корректными параметрами автоматически сохраняется в браузере. Вкладка изменений показывает отличия от базовых профилей.
6. Экспортируйте JSON для резервной копии или передачи другому игроку. Импорт проверяет параметры до изменения черновика.

Базовые значения относятся к GrimCraft. Значения из другой версии Warhammer нужно вводить в мод явно и проверять вместе с соответствующими AP/точностью/интервалом.

## Проверка

На вкладке **Тестовая арена** задайте броню и HP цели, число стрелков, длительность, точность стоя/в движении и seed. Тест рассчитывает Go через `POST /api/balance/test`, используя те же правила попадания, что применяются к модифицированному оружию в мультиплеере.

```sh
cd ../grimcraft-go
go run ./cmd/server
```

HTTP API по умолчанию: `http://127.0.0.1:8080`. Для тестовой арены достаточно `go run ./cmd/server --no-wt`.

Арена — стрелковый расчёт против неподвижной цели с выбранным классом брони, без пути, укрытия, ответного огня и анимаций. Урон успешного попадания берётся средний; случайность применяется к точности. Первый залп выполняется через один Refire, затем повторяется с этим интервалом. Максимум 100 стрелков, 300 секунд и 200 000 выстрелов. Одинаковые параметры и seed воспроизводят результат.

## Применение

**Выбрать мод** сохраняет корректный мод для следующей одиночной игры. Перейдите в игру и запустите новый матч. Для возврата к исходным характеристикам нажмите **Отключить мод** в редакторе. Уже начатый матч не меняется.

В сетевом лобби хост может включить выбранный мод перед **Start Game**. Go проверяет мод, фиксирует его копию и отправляет игрокам название, версию, параметры и SHA-256. Мод нельзя менять после старта. Чужой локальный мод не применяется поверх параметров комнаты.

Меняются только оружия, записанные в `weapons`. Остальные сохраняют прежнее поведение. В первой версии сетевое применение относится к стрельбе отрядов по бойцам; стрелковая арена позволяет отдельно проверить все 15 типов брони.

Формат: `schemaVersion: 1`, `id`, `name`, `version`, `weapons`. Каждый изменённый профиль содержит `mode`, `minDamage`, `maxDamage`, `minimumDamage`, `accuracy`, `movingAccuracy`, `refire`, `range`, `armorPiercing`, `dps`. Точность хранится от 0 до 1, AP — от 0 до 100. Интервал — 0,05–300 секунд. Файл мода не содержит исполняемого кода.
